# Релиз: семейный календарь (не коммерция)

Достаточно для одной семьи / нескольких доверенных семей на своём сервере или VPS.

## Что умеет

- Общий календарь (день/неделя/месяц/список), drag & resize
- Участники + роли (мама/папа/…) + цвета
- Конфликты и буфер на дорогу
- Повторяющиеся события
- Приглашения (ссылка / код)
- Realtime, напоминания, Web Push
- Refresh-сессии, сброс/смена пароля
- Онбординг новой семьи

## Перед деплоем

### 1. Секреты (обязательно)

```bash
# сильный секрет ≥32 символов
openssl rand -hex 32

# свои VAPID (не копируйте из .env.example)
npx web-push generate-vapid-keys
```

В `.env` на сервере:

| Переменная | Пример |
|---|---|
| `NODE_ENV` | `production` |
| `DATABASE_URL` | Postgres URL |
| `JWT_SECRET` | длинная случайная строка |
| `JWT_ACCESS_EXPIRES_IN` | `15m` |
| `JWT_REFRESH_EXPIRES_DAYS` | `30` |
| `CORS_ORIGIN` | `https://calendar.your.domain` |
| `WEB_ORIGIN` | то же, для ссылок сброса пароля |
| `VITE_API_URL` | `https://api.your.domain` (сборка web) |
| `VAPID_*` | свои ключи |
| `ENABLE_SWAGGER` | не задавать (Swagger в prod выключен) |

При `NODE_ENV=production` API **не стартует** без нормального `JWT_SECRET` и `CORS_ORIGIN`.

### 2. База

```bash
pnpm db:migrate
# seed только для демо, на прод-семью не нужен
```

### 3. Сборка и запуск

```bash
pnpm install
pnpm build
# API
cd apps/api && NODE_ENV=production node dist/main
# Web — статика (nginx) из apps/web/dist
```

HTTPS обязателен для Web Push вне localhost.

### 4. Сброс пароля

Сейчас письмо только в **лог API** (+ `devResetUrl` вне production).  
Для семьи на LAN/VPS: смотрите лог или зайдите в меню → «Сменить пароль» будучи залогиненым.  
SMTP можно дописать позже (`SMTP_URL` заготовка).

### 5. Smoke-чеклист (15 мин)

- [ ] Регистрация / логин / refresh (обновить страницу через 15+ мин с access 15m)
- [ ] Создать семью (онбординг) или войти в существующую
- [ ] CRUD событие, drag, пересечение, буфер
- [ ] Участник + категория; удаление с проверками
- [ ] Приглашение по ссылке и коду
- [ ] Напоминание / колокольчик / (опционально) Web Push
- [ ] Выход и сброс пароля (ссылка из лога)

### 6. Бэкап

Раз в день (или чаще) дамп Postgres:

```bash
pg_dump "$DATABASE_URL" > backup-$(date +%F).sql
```

## Что сознательно не делали

- Платежи, мультитенант SaaS, админка
- Жёсткий ACL помощника, аватары, Google/Apple sync, PWA
- Полноценный SMTP (пока лог)

Для домашней семьи этого достаточно.
